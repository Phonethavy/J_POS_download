## ຕິດຕັ້ງ / Install

1. ເປີດໄຟລ໌ `JPOS-Setup.exe` ທີ່ດາວໂຫຼດມາ / Run the downloaded installer
2. ຖ້າ Windows ຂຶ້ນ "Windows protected your PC" → ກົດ **More info** → **Run anyway**
3. ເລືອກບ່ອນຕິດຕັ້ງ ແລ້ວກົດ Install / Choose a folder and click Install
4. ເປີດ JPOS ຈາກ shortcut ເທິງ Desktop / Open JPOS from the desktop shortcut
